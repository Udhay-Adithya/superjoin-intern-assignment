Each card shows the rule that fired and both sides' evidence.

A cluster groups facts sharing an entity, metric and period — the set the comparison engine reasons over. Clusters spanning several documents are where cross-document reconciliation happens.

The PDF is parsed, segmented, extracted, grounded and reconciled against everything already ingested. Only clusters the new document touches are recomputed.
